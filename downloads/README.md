# McQueen premium prototype

[Download the Netlify-ready ZIP](https://github.com/kylebraiden/GetclientcaptureKB/raw/refs/heads/main/downloads/mcqueen-premium-netlify.zip)

On the ZIP's GitHub page, use **Download raw file** if needed. This is the compiled website, including all 87 portfolio previews; no build configuration is needed.

For Netlify manual deployment, extract the ZIP and drag the extracted folder containing `index.html` and `assets/` into Netlify Drop. Uploading these files to GitHub alone does not publish a live website.

The enquiry form is a private demonstration and does not send submissions. Artist copy and portfolio images remain provisional. Final design review and real-phone testing are still needed before public release.
